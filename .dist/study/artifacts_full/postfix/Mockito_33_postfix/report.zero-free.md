The bug occurs when a mock object is cast to an interface that defines a method with generic type parameters (e.g., Iterable.iterator()). The original implementation relied on Method.equals() to match invocations. However, when a class implements an interface with generics, the bridge method generated by the compiler has a different signature (often returning Object instead of the specific type) than the interface method, causing Method.equals() to return false even though they represent the same logical method. The fix replaces the strict Method.equals() check with a custom comparison that checks method names and parameter types, ensuring that bridge methods are correctly identified as matching the interface methods.
